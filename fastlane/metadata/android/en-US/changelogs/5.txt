OAuth logins that end on a Microsoft sign-in page are now captured instead of loaded: the one-time code in the address is handed to the share sheet in one tap. The capture is a visible state: a banner names the source and the time, the share button becomes the code share, the state survives navigation, expiry turns the banner amber instead of hiding it, and after sharing the app concludes with a dedicated screen. The landing rule is now a profile list, ready for more identity providers.
